# Digitised experimental reference (Hatakeyama et al. 2012)

Manual digitisation of PIV $U_y(x)$ markers at $Z=7$ mm, and PBGA temperature rise ΔT.

Source files: `Electronic-Cooling/References/validation-benchmarks/Xin{Xin}-Y{Y}.csv`
(and the corresponding PNG scans). Copied here with headers `x_mm,Uy_mps` and sorted by $X$.

| Case file | Station |
|-----------|---------|
| `fig6_Y60.csv` | $Y=60$ mm |
| `fig6_Y80.csv` | $Y=80$ mm |
| `fig6_Y100.csv` | $Y=100$ mm |
| `fig6_Y120.csv` | $Y=120$ mm |
| `fig6_Y140.csv` | $Y=140$ mm |
| `fig7.csv` | PBGA $\Delta T$ vs Xin |

ΔT came from the published temperature-rise plot (left axis, K).

Paper: Hatakeyama, T., Ishizuka, M., Kibushi, R., Nakagawa, S. (2012). *A Test Bench for Validation of CFD Analysis for Air Flow in Thin Electronic Casing Model.* J. Phys.: Conf. Ser. 395 012024.

Digitisation scatter of a few tenths of a millimetre / a few cm/s is expected.
